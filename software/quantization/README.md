# 量化工作

1. `00_preprocess_check/`：确认模型实际收到的图像像素。当前 RTL 使用灰边 114 和隔行隔列取样；固定 640×640 的 Ultralytics 参考使用灰边 114 和线性缩放。
2. `01_fp32_preprocess_accuracy/`：在 35 张验证图上比较标准预处理与 RTL 一致预处理的 FP32 检测结果；当前结果没有新增漏检。
3. `02_calibration_data/`：从 143 张训练图生成 RTL 一致的 640×640 校准输入，不使用验证集；此步骤不执行量化。
4. [`03_int8_ptq/`](03_int8_ptq/README.md)：审计推理图，导出 FP32 ONNX 并与 `.pt` 比较；使用 143 张图校准卷积 W8A8，记录 PE 数值参数，再用 35 张保留图验收混合精度候选模型。

每次实验应把脚本、配置和结果摘要放在一起。生成的预览图和大型临时文件放入本地 `results/` 子目录。
